## v1.7.3

### 修复

- **视频缩略图稳定性修复**：
  - 并发首次加载不再返回 429：非阻塞 2 槽信号量改为阻塞排队（4 槽 + 8s 超时），突发批量请求排队等待而非丢弃
  - 排队后二次检查缓存，避免重复运行 ffmpeg
  - 短视频回退：`-ss 5` 失败时自动回退首帧（`-ss 0`），消除 <5s 视频缩略图 404
  - 错误响应添加 `Cache-Control: no-store`，前端重试可真正重新请求
  - 删除 ffmpeg 失败后的空/损坏缓存文件

### 改进

- **前端缩略图重试与降级**：
  - `onerror` 触发指数退避重试（3 次），覆盖临时拥塞或生成延迟
  - 彻底失败时隐藏 `<img>`（新 CSS 类 `.file-thumb--failed`），不再显示碎图图标

### 变更文件

- `internal/handler/thumbnail.go`（重写生成逻辑：排队 + 短视频回退 + no-store + 二次缓存检查）
- `web/src/modules/ui/render.js`（新增 `setupThumbRetry()` 重试/降级辅助函数）
- `web/src/styles/components/list.css`（新增 `.file-thumb--failed` 隐藏规则）
