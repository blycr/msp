# v1.1.1 Release Notes

## 前端架构深度重构

将 `player.js`（579 行）和 `playlist.js`（175 行）转为薄编排层，仅包含 re-export 和 bus 监听，零业务逻辑。

**player.js 精简至 51 行：** 提取 `player/play.js`（`playItem` + `onMediaEnded`），消除 `player.js ↔ player/resume.js` 循环依赖。所有业务逻辑分散在 `player/` 子目录的 6 个模块中。

**playlist.js 精简至 45 行：** 将 `setPlaylist` 移入 `playlist/navigation.js`，通过 `bus.emit('playlist:updated')` 触发 UI 更新，替代原来的直接函数调用。

**循环依赖消除：** `actions.js ↔ ui/bindings.js` 的循环依赖通过 bus 事件（`config:reload`、`media:refresh`）解耦。

---

## 代码去重

- `rememberEnabled`：3 处独立实现统一为 `api.js` 中的单一实现
- `canStorage`：2 处独立实现统一为 `state.js` 中的单一实现

---

## 死代码清理

移除 7 个未使用的导出（`I18N`、`mediaErrorText`、`getSortVal`、`hidePinDialog`、`verifyPin`、`switchAudioTrack`、`getAudioTracks`）和 1 个无监听者的 bus 事件（`ui:render`）。

---

## PWA 优化

VitePWA 启用 `cleanupOutdatedCaches`、`skipWaiting`、`clientsClaim`，Service Worker 更新时自动接管旧版本，用户无需手动刷新。

---

## I18N 完善

- 歌词纯音乐提示文案（"Pure Music / 请欣赏"）改为 i18n key `lyrics_pure_music`
- 页面 `<html lang>` 从 `zh-CN` 改为 `en`，`<title>` 统一为 `MSP Media Share`

---

## 构建脚本

新增龙架构（loong64）Linux 构建支持，`build-profiles.json` 的 `all`、`release`、`linux` 预设均已包含。
