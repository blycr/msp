## v1.9.2

### 修复

- **音频页在全屏/大屏下舞台下方大片空白**：歌词区固定 320px、封面固定 200px、整个 audioMeta 顶部对齐，1080p 下约 50%、1440p 下约 58% 的舞台高度闲置。现 audioMeta 改弹性布局填满舞台剩余高度，歌词区随之撑满，封面相对歌词列垂直居中
- **视频/图片未能真正贴边**：`#audioEl` 用 inline `display:none` 隐藏而非 `hidden` 属性，导致 `.playerbox:has(#audioEl:not([hidden]))` 恒匹配，playerbox 常驻 20px padding。现 `#audioEl` 在显隐切换时同步 `hidden` 属性（初始 HTML 亦带 `hidden`），非音频模式 padding 归零，媒体零缝隙铺满舞台
- **超宽屏下侧栏过宽**：三栏原为 fr 比例（0.82/1.8/0.82），1440p 下侧栏达 587px，文件名后大片空白。侧栏改为 `minmax(260px, 360px)`，多余宽度让给舞台
