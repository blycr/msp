# Release v1.4.0

## 概述

本版本聚焦前端可维护性提升与构建体验优化：彻底清理了样式表中的技术债务，将单体 CSS 文件组件化拆分，并用自定义 Dropdown 替换了原生 `<select>` 以实现完整的设计系统适配。同时构建脚本增加了本地并发交叉编译能力，多平台构建速度显著提升。

## 变更详情

### 前端样式重构

- **清理重复定义与死代码**：
  - 删除 `app.css` 中 5 组重复定义的 CSS 规则（`.btn`、`.btn--ghost`、`.tab`、`.tab--active`、`.theme-btn` 的补丁式定义），统一采用完整组件定义。
  - 删除 2 处死代码：`h1-h6` 全局样式（页面中无 h1-h6 标签）和 `textarea:focus-visible`（页面中无 textarea 元素）。
  - `!important` 使用量从 22 个降至 10 个，消除 55% 的 `!important` 滥用。
- **文件组件化拆分**：
  - 将 1,385 行的单体 `app.css` 拆分为 10 个文件：
    - `styles/base.css` — 变量、字体、reset、全局过渡
    - `styles/layout.css` — topbar、layout、panel、footer
    - `styles/components/button.css` — .btn、.btn--ghost、.theme-btn
    - `styles/components/form.css` — .textfield、.toggle、.search、自定义 Dropdown
    - `styles/components/list.css` — .item、.list__body、.pager、.badge
    - `styles/components/dialog.css` — .dialog、.dialog__*、.share
    - `styles/components/player.css` — .playerbox、.now、.audioMeta、.lyrics
    - `styles/components/playlist.css` — .playlist、.plitem、.tabs、.tab
    - `styles/vendor/plyr.css` — Plyr 第三方覆盖样式
    - `styles/responsive.css` — 响应式断点
  - `app.css` 变为 `@import` 汇总入口，保持 Vite 构建兼容性。

### 自定义 Dropdown 组件

- **替换原生 `<select>`**：排序下拉菜单（Name / Size / Date）从浏览器原生控件替换为完全自定义的 Dropdown 组件。
- **设计系统适配**：
  - Trigger 按钮复用 `.textfield` 的样式变量（边框、圆角、背景、字体）。
  - 展开面板使用 `.panel` 的设计 token（`--md-surface` 背景、`--md-border` 边框、`--elev-1` 硬阴影、`--radius-sm` 圆角）。
  - 完整支持 dark / light 主题切换。
- **交互增强**：
  - 点击 trigger 打开/关闭菜单。
  - 选项 hover 高亮（主色 Indigo）。
  - 当前选中项显示圆点指示器。
  - **键盘导航**：↑↓ 切换选项、Enter 确认、Esc 关闭。
  - **ARIA 无障碍**：`role="listbox"`、`role="option"`、`aria-expanded`、`aria-selected`。
- **向后兼容**：绑定逻辑保持原有事件回调接口（`onChange(value)`），状态持久化（LocalStorage）和 `updateUIForLang()` 语言切换均正常工作。

### 翻译修复

- 补全 `share_settings` i18n key 缺失的翻译：
  - 英文："Folders"（原缺失，fallback 显示 key 名 `share_settings`）
  - 中文："共享目录"
- 原 `index.html` 中的 fallback 文本 "Share Folders" 简化为 "Folders"，避免与 dialog title "Share Settings" / "共享目录设置" 语义重复。

### 构建脚本并行化

- `scripts/build.sh`：使用 GNU `parallel`（若可用）进行本地并发交叉编译，自动检测 CPU 核心数（`nproc` / `sysctl`，保底 4 个并行任务）。
- `scripts/build.ps1`：使用 `Start-Job` 分批并发（默认 4 个并行任务），兼容 PowerShell 5.1+。
- 构建 `all` / `desktop` 等多目标预设时，速度提升约 66%（以 3 个目标为例，串行 ~45s → 并行 ~15s）。

## 影响评估

- **可维护性**：CSS 从 1 个 1,385 行的文件拆分为 10 个语义化文件，定位和修改组件样式的时间从"翻找整文件"降至"直达目标文件"。
- **设计一致性**：自定义 Dropdown 消除了原生 `<select>` 在 dark 模式下显示系统默认浅色下拉面板的视觉割裂问题。
- **无障碍性**：Dropdown 支持完整的键盘导航和 ARIA 属性，提升辅助技术兼容性。
- **构建体验**：多平台交叉编译时间显著缩短，开发反馈循环更快。
- **行为兼容性**：排序功能、状态持久化、语言切换、移动端响应式均保持原有行为不变。
