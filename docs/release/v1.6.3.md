# Release v1.6.3

## 继续观看（Continue Watching）

打开 MSP 首页，侧边栏顶部自动显示上次看到一半的视频/音频，点击一键续播。

- 后端新增 `/api/progress/recent?limit=N` 端点，按更新时间降序返回最近播放记录。
- 前端启动时自动拉取并与当前媒体库做 join 映射。
- 搜索模式下自动隐藏，避免干扰。

## 文件夹层级浏览（Folder Browse）

电视剧按季/集分目录存放时，可通过目录树浏览，告别 500+ 文件的扁平列表。

- 后端扫描时计算 `relPath`（相对于 share root 的目录路径）。
- 前端支持 `flat` / `folder` 双模式切换。
- 文件夹模式下显示面包屑、子文件夹和当前目录文件。

## 收藏/标记（Favorites）

遇到想稍后观看的影片？点击星标收藏，跨类型聚合查看。

- 后端 `/api/favorites` 提供完整的增删查 API。
- 列表项右侧 ☆/★ 一键切换，即时同步。
- 新增第五个 `Favorites` Tab，所有收藏文件聚合展示，支持搜索/排序/分页。
- 收藏 Tab 下自动隐藏"继续观看"和文件夹浏览，保持聚焦。

## 视频缩略图（Video Thumbnails）

视频列表从纯文件名升级为带缩略图的视觉化列表。

- 后端 `/api/thumbnail?id=xxx` 使用 ffmpeg 截取第 5 秒画面。
- 缩略图缓存到 `thumbs/` 目录，带 24h HTTP 缓存头。
- 并发限制为 2 个 ffmpeg 任务，避免资源风暴。
- 前端懒加载显示，ffmpeg 不可用时优雅降级。

## 转码进度反馈（Transcode Status）

播放需要转码的视频时，不再面对空白等待。

- 播放器上方显示"检测兼容性..." → "正在转码，请稍候..."状态提示。
- 媒体可播放后自动消失。

---

**兼容性**：
- 旧数据库会自动通过 GORM `AutoMigrate` 添加 `favorites` 表和 `rel_path` 列。
- 旧数据需重新扫描才能完整体验文件夹浏览（已有 `rel_path` 数据）。
