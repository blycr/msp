## v1.8.0

### 改进

- **前端 UI 设计系统统一**：
  - 统一 SVG 图标系统：`icons.js` 重构为图标注册表，单一出口 `icon(name)`；Settings 改为滑杆图标、Refresh 改为 refresh-cw；📁/★/☆/←/▶ 等文本字形图标全部 SVG 化，界面不再出现 emoji 图标
  - 新增通用分页组件 `ui/pager.js`：文件列表与播放列表共用，chevron 图标按钮替代文本按钮，删除 3 处重复实现
  - 全局隐藏滚动条（滚动功能不变），界面更沉浸
  - 设计 token 收尾：新增 `--ring`/`--stage-bg`/`--stage-media-bg`/`--shadow-dialog`，焦点环、播放器沉浸底、弹窗阴影全部 token 化，暗色主题自动适配
  - 按钮体系统一：`.icon-btn`/`.theme-btn`/`.fav-btn` 同一规格，按钮阴影改 `color-mix` 随主题变化
  - 响应式媒体工作区整体打磨（移动端导航、面板布局、组件样式）
- **后端性能优化**：
  - 日志改为异步缓冲写入（`logChan` 容量 4096 + 单一写 goroutine），写满丢弃不阻塞请求
  - 多共享目录并行扫描（goroutine + WaitGroup），大媒体库扫描更快
  - `/api/media` ETag 快速路径：`If-None-Match` 命中直接 304，不再构建响应
  - SQLite 连接池按 GOMAXPROCS 调整；新增 `LOWER(name)`、扫描排序复合、progress/favorites 时间等索引
  - GC 调参：`SetGCPercent` 50 → 100

### 修复

- 修复 `.theme-btn svg { fill: currentColor }` 覆盖图标本体 `fill="none"`，导致日/月主题图标被意外填充
- 修复空态 play 图标 data-URI 被 CSP `img-src 'self'` 拦截（改为真实 SVG 元素）
- 修复部分 Windows PowerShell 5.1 环境缺失 `Get-FileHash` 导致 `build.ps1` 全量编译在校验和步骤失败：`build.ps1`/`dev.ps1` 检测到 PS < 7 时自动以 pwsh 重新执行
- Dockerfile 后端构建镜像升级 `golang:1.25-alpine`，与 go.mod 对齐（此前靠 toolchain 自动下载兜底）
- 修复 auth/thumbnail handler 的 golangci-lint 警告
