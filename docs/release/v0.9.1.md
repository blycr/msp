# v0.9.1 Release Notes

## 改进与修复

### 音频转码默认开启
- `config.json` 自动生成时，`playback.audio.transcode` 默认值由 `false` 改为 `true`
- 避免 Firefox 等浏览器遇到不支持的音频格式时直接报错 "Transcode Disabled"
- 已存在的配置文件不受影响，仅对新生成的配置生效

### 前端格式兼容性增强
- 扩展 `mimeFor()` 支持的格式映射：
  - 视频新增：`.flv`, `.ts`, `.m2ts`, `.mts`, `.mpg`, `.mpeg`, `.3gp`, `.3g2`, `.qt`
  - 音频新增：`.wma`, `.ape`, `.mka`, `.weba`, `.mid`, `.midi`, `.f4a`, `.wave`, `.oga`, `.spx`
- 放宽 `canPlayMedia()` 判断逻辑：
  - 未知/未识别格式允许尝试直接播放，不再直接拦截
  - 已知格式仅在 `canPlayType` **明确返回空字符串**时才拦截，减少 Firefox 误拦截

### Firefox 兼容性
- 针对 Firefox 浏览器 `audioMeta` 区域偶发黑块问题添加兼容性处理
- 通过 `transform: translateZ(0)` 强制 GPU 合成层，避免 opacity transition 渲染异常
- Chrome 及其他浏览器体验完全不受影响

### 依赖更新
- 前端：`vite` 7.3.1 → 8.0.10，`vite-plugin-pwa` 同步更新
- 后端 Go 依赖升级：
  - `github.com/mattn/go-isatty` v0.0.20 → v0.0.22
  - `golang.org/x/exp` 更新至最新
  - `golang.org/x/sys` v0.41.0 → v0.43.0
  - `golang.org/x/text` v0.34.0 → v0.36.0
  - `modernc.org/libc` v1.67.7 → v1.72.1
  - `modernc.org/sqlite` v1.45.0 → v1.50.0
