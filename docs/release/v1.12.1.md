## v1.12.1

### 修复

- **文件夹范围播放列表失效**：视频/图片默认 `scope: folder`，但前端仍把加密后的媒体 ID 当路径做 base64 解码，同目录下一集/下一张经常只剩当前文件。现按 `relPath` + `shareLabel` 分组
- **设置页保存过滤会关掉 PIN**：UI 把不含 `pinHash` 的 SafeConfig 整包写回，服务端替换配置后 `ApplyDefaults` 将 PIN 关闭并落盘。现保留已有哈希，响应也不再带回 `pinHash`
- **长流大约 60 秒断开**：`http.Server.WriteTimeout` 覆盖整段响应写出，直连大文件、渐进式转码、长有声书会被掐断（HLS 分段不受影响）。现去掉该超时，慢连接仍由 `ReadHeaderTimeout` 约束
- **缩略图可指向分享目录外的文件**：`/api/thumbnail` 只解码 ID 后 `Stat`，未走 `IsAllowedFile`。现与 `/api/stream` 共用 `resolveMediaTarget`
- **`msp.key` 创建失败会静默降级**：ID 变成路径的 base64，可被猜测。现启动失败即退出
- **Docker 裸跑无法启动**：镜像二进制在 `/opt/msp-server`，`CMD` 却是 `./msp-server`。现改为绝对路径，并增加 `HEALTHCHECK`
- **Release 产物文件名错误**：`msp-linux-arm-armv7`、`msp-linux-loong64-loong64`、`msp-windows-386-386.exe` 与文档/本地脚本不一致。现与 `scripts/README.md` 对齐
- **配置热重载会吃下非法文件**：`Validate` 此前只在测试里跑。现加载/API/热重载都会校验，热重载失败保留旧配置
- **扫描时进度/收藏偶发写失败**：`busy_timeout` 等 PRAGMA 只打在第一条连接上。现写入 DSN，连接池上限改为 4
- **PIN 连点可打穿锁定**：失败计数在锁外自增。现锁内更新

### 新功能

- **超宽屏布局封顶**：`.layout` 容器 `max-width: 2736px` 居中（替代不兼容的 `min(1fr, 1920px)`），超宽显示器上三栏不再被拉得过散
- **版本可见**：启动横幅与 `GET /healthz` 返回 `version`（构建时 `-X main.version=`）

### 说明

- 分享目录里的 SVG 改为 `Content-Disposition: attachment`，预览页不再当图片内嵌
- 缩略图 `Cache-Control` 改为 `private`，并去掉 Service Worker 对 `/api/thumbnail` 的 StaleWhileRevalidate
- 打 tag 发布时必须存在 `docs/release/<tag>.md`，且 release 工作流会先跑 check
- `docker compose` 增加 `init: true` 与 healthcheck；数据卷行为不变（entrypoint 仍把二进制拷到 `/app`）
