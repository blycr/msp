# v1.2.1 Release Notes

## 测试覆盖率提升

本版本重点提升了核心模块的自动化测试覆盖率，确保认证、会话管理以及媒体流处理的稳健性。

### 新增测试文件
- **`internal/handler/auth_test.go`**：补全了 PIN 认证流程的单元测试，覆盖了验证成功、验证失败、限流保护等场景。
- **`internal/service/session_test.go`**：新增会话管理逻辑测试，验证会话创建、有效期检查以及清理机制。

### 增强现有测试
- **`internal/handler/stream_test.go`**：补全了媒体流探测与播放策略的边界条件测试。
- **`internal/handler/subtitle_test.go`**：增强了外挂字幕自动探测与转换逻辑的测试覆盖。
- **`internal/server/server_test.go`**：优化了服务器启动与配置加载的集成测试。
- **`internal/util/util_test.go`**：补全了路径规范化与权限检查工具函数的测试。

---

## 代码质量优化

- **消除 Lint 警告**：修复了 `internal/handler/stream_test.go` 中 `unusedparams` 的诊断警告，移除了冗余的 `configPath` 参数，保持代码库整洁。
- **错误处理规范化**：修复了测试代码中多处未检查的错误返回值，确保测试过程的严谨性。
