# Release v1.5.0

## 概述

本版本是一次全面的安全加固 release，基于内部安全审计修复了 14 项漏洞（P0–P3），覆盖认证、访问控制、文件流安全、HTTP 安全头和媒体 ID 加密。同时引入了三级访问分级（Local / LAN / Remote），为不同网络环境的用户提供差异化的功能暴露策略。

**⚠️ 破坏性变更**：媒体 ID 从 base64 编码路径升级为 AES-GCM 对称加密，旧版本收藏的 `?id=...` 书签会失效（返回 "bad id"），需要重新收藏。

## 变更详情

### 认证安全

- **PIN 暴力破解防护**：连续 5 次错误 PIN 后锁定 15 分钟，per-IP 内存计数器（惰性清理）。
- **取消弱默认 PIN**：`DefaultPIN` 从 `"0000"` 改为 `""`（空字符串），空 PIN 拒绝验证。
- **常数时间 PIN 比较**：使用 `crypto/subtle.ConstantTimeCompare` 替代普通字符串比较，消除时序侧信道攻击风险。
- **配置死锁防护**：若配置为 `pinEnabled: true` 但 `pin: ""`，自动降级为 `pinEnabled: false`，避免管理员锁定自己。

### 访问控制

- **三级访问分级**：
  - `Local`（localhost / 127.0.0.1 / ::1）：完整功能，设置按钮可见，管理 API 可用。
  - `LAN`（RFC1918 私有地址）：设置按钮隐藏，管理 API（POST `/api/config`、`/api/shares`）返回 403，配置响应过滤敏感字段（隐藏 shares path、port、logLevel、blacklist 等）。
  - `Remote`（公网 / Cloudflare Tunnel）：设置按钮隐藏，管理 API 403，配置响应清空所有敏感字段（URLs、LAN IPs、shares、blacklist、whitelist 等）。
- **Cloudflare Tunnel 识别**：回环地址同时携带 `CF-Connecting-IP` 或 `CF-Ray` 头时，正确识别为 Remote 而非 Local。
- **Admin Lockdown 中间件**：非 Local 访问直接阻止管理类 POST 请求。

### 限流与 DoS 防护

- **全局限流器**：基于 Token-Bucket 算法，per-IP，Local 豁免。
  - `/api/pin`：1 req / 5s，burst 5
  - `/api/media?refresh=1`：1 req / 30s，burst 1
  - `/api/stream`：2 req / s，burst 10
  - 其他 `/api/*`：10 req / s，burst 20
- **Refresh DoS 冷却**：`?refresh=1` 全局 30 秒冷却，防止扫描进程被恶意频繁触发。
- **WriteTimeout**：从缺失修复为 60 秒，防止慢客户端占用连接。

### 文件流安全

- **TOCTOU 竞态修复**：`resolveMediaTarget` 在 `os.Open` 后二次执行 `filepath.EvalSymlinks` + `IsAllowedFile` 验证，防止符号链接竞态绕过路径限制。
- **Inline XSS 防护**：非媒体扩展名（非视频/音频/图片/字幕）的文件流强制返回 `Content-Disposition: attachment`，阻止浏览器内联执行恶意内容。

### HTTP 安全头

- **Content-Security-Policy**：`default-src 'self'` 等完整策略，仅允许必要的 CDN 来源（`cdn.plyr.io`、`static.cloudflareinsights.com`）。
- **HSTS**：HTTPS 请求（含 `X-Forwarded-Proto: https`）自动添加 `Strict-Transport-Security: max-age=31536000; includeSubDomains`。
- **移除废弃头**：删除已废弃的 `X-XSS-Protection: 1; mode=block`（依赖 CSP 即可）。
- **Cookie 安全**：通过 HTTPS 代理（如 Cloudflare Tunnel）时，session cookie 自动设置 `Secure` 标志。

### 媒体 ID 加密

- **AES-GCM 对称加密**：新增 `internal/util/crypto_id.go`，启动时自动加载/生成 32 字节密钥（`msp.key`，权限 0600）。
- **EncodeID / DecodeID**：媒体路径加密为 URL-safe base64，不再直接暴露文件系统路径。
- **向后兼容**：若密钥丢失/未配置，回退到 plain base64（功能降级，不影响可用性）。

### 其他安全修复

- **客户端日志注入防护**：`/api/log` 接口增加 level 白名单（debug/info/warn/error）和消息截断（500 字符）+ 换行过滤。
- **IP 黑白名单 CF 修复**：当请求来自回环且携带 Cloudflare 头时，使用 `CF-Connecting-IP` 评估黑白名单，而非 `127.0.0.1`。
- **信息泄露清理**：移除 `web/index.html` footer 中的 GitHub 项目链接。

### 前端配套

- `state.js` 新增 `accessLevel` 状态，根据后端响应动态分级。
- 非 Local 环境自动隐藏"Settings"按钮，禁止打开设置弹窗。
- Remote 环境不触发 `meta:update`（不显示内网访问地址）。
- 新增 `hint_noshare_local` / `hint_noshare_remote` 分级提示翻译。

## 影响评估

- **安全性**：14 项漏洞修复，攻击面显著缩小。媒体 ID 加密消除路径信息泄露；限流器阻止暴力破解和 DoS；访问分级确保敏感管理功能仅对本地暴露。
- **破坏性**：旧 base64 ID 书签失效，需重新收藏。
- **性能**：限流器和访问分级检查对 Local 访问零开销；AES-GCM 加解密对媒体列表构建的影响可忽略（单次加密，缓存复用）。
- **配置兼容性**：`config.json` 格式完全向后兼容，无需手动迁移。
