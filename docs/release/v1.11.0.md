## v1.11.0

### 修复

- **视频播放进度从不保存（回归）**：进度恢复管线完整但写入端缺失——`plyrPersistTimer` 声明后从未赋值，无任何周期性/卸载时保存，视频续播实际无效。现恢复 10s 节流保存（timeupdate）+ 播放结束保存 + `pagehide` 卸载保底，遵守 `remember` 配置；移除无效遗留代码
- **文档与代码不符**：README/README_CN 将 `AVI`、`WMV` 列为预转码容器（实际按编码决策，无法嗅探的容器走直连 + 错误回退）；TRANSCODING.md 的 `playback.video.transcode` 默认值（实为 `false`）与示例命令 `-b:a 192k`（代码未设置）一并修正

### 新功能

- **MKV 内嵌字幕**：`/api/probe` 经 ffprobe 返回内嵌文本字幕轨道，与侧车字幕合并（zh 优先、首轨默认）；`/api/subtitle?id=&track=N` 提取内嵌轨道为 WebVTT。图像字幕（PGS/DVD/DVB）不转换、探测时过滤
- **编解码检测统一**：播放决策（direct/transcode）改以 ffprobe 为准（5 分钟缓存），字节嗅探降级为 ffprobe 不可用时的兜底——决策与转码参数共用同一数据源，消除两条检测路径不一致
- **转码流 seek/Range 支持（HLS）**：视频转码输出改为 HLS（ffmpeg 4s 分段 + m3u8 全量列表），段文件经 `/api/hls/<sessionID>/<file>` 服务（原生 Range），拖动进度条不再重建播放源；会话 5 分钟无访问自动清理、启动时清理残留临时目录；前端接入 vendored hls.js（Safari 原生 HLS，不支持时回退渐进式）。音频转码维持渐进式 mp3（`&start=` 时间 seek）
- **启动二维码**：启动横幅在局域网地址下打印二维码（ANSI 黑白块），手机连同一局域网扫码直达；`127.0.0.1` 本机地址不打印，生成失败不影响启动

### 说明

- 新增依赖 `github.com/skip2/go-qrcode`（纯 Go，无传递依赖）
- 内嵌字幕仅在播放时探测（scan 不检测，保持扫描性能），探测与提取均需 ffmpeg/ffprobe 可用
- HLS 段文件写入系统临时目录（`msp_hls_*`），播完/超时自动删除；码率由转码参数决定
