# MSP v0.8.8 发布说明

## 修复随机播放逻辑

v0.8.8 彻底重构了音频随机播放功能，解决了之前版本中随机模式下的多个逻辑问题。

### 问题修复

- **随机播放序列保持**: 之前每次点击歌曲都会重新打乱播放列表，导致无法预知下一首。现在播放列表顺序固定，通过独立的播放序列实现随机播放
- **切换随机模式不中断**: 开启/关闭随机模式时，当前播放的歌曲位置保持不变，仅重新排列后续播放顺序
- **上一首/下一首正确导航**: 随机模式下，上一首/下一首按钮现在按照实际的播放历史导航，而非按列表顺序
- **播放列表高亮正确**: 当前播放歌曲在播放列表中高亮显示正确，不受随机顺序影响

### 技术改进

- 新增 `playOrder` 数组存储播放顺序映射
- 新增 `playIndex` 跟踪当前播放位置
- 分离数据存储与播放顺序逻辑
- 支持循环播放模式下的正确导航

### 其他改进

- 全仓库清理 emoji 字符，保持文档简洁专业
- 保留 SVG 图标和视觉元素的美观性
