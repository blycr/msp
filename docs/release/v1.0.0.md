# v1.0.0 Release Notes

## 正式版发布

MSP 迎来第一个正式版本 v1.0.0！经过多个版本的迭代和重构，项目已达到生产就绪状态。

---

## 架构重构

### 后端架构升级

- **Domain 层**: 提取领域类型到 `internal/domain/`，零外部依赖
- **Storage 层**: 新建 `internal/storage/` 包，移除全局 `db.DB`，实现接口化存储
- **Scanner 包**: 从 `media` 包拆出 `internal/scanner/`，职责更清晰
- **Cache 层**: 提取 `internal/cache/media.go`，支持内存 + 磁盘缓存
- **Service 层**: 新增业务编排层（配置、会话、日志、媒体服务）
- **Handler 层**: 依赖接口而非具体实现，消除循环依赖
- **Server 层**: 瘦身至 199 行，职责委托给各 Service

### 前端架构升级

- **EventBus**: 新增发布/订阅事件总线，解耦模块间通信
- **Player 模块**: 拆分为 6 个文件（core, resume, transcode, audio-track, seek）
- **Playlist 模块**: 拆分为 4 个文件（sort-filter, navigation, render）
- **UI 模块**: 拆分为 5 个文件（render, settings, shares, bindings）

---

## 新特性

### 优雅关机
- 监听 `SIGINT`/`SIGTERM` 信号
- 自动终止 FFmpeg 转码进程
- 等待在途请求完成（超时 10s）

### ffprobe 结果缓存
- 使用 `sync.Map` + TTL（默认 5 分钟）
- 缓存键：`filepath + mtime`

### 正则预编译
- `scanner` 包预编译所有正则表达式，提升性能
