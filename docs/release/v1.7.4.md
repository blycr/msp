## v1.7.4

### 改进

- **随机播放算法改为"洗牌包"（shuffle bag）**：
  - Fisher-Yates 全排列，一轮内每个文件恰好播一次、绝不重复（满足"不想重复听到之前播放过的音乐"）
  - 一轮播完后自动重洗生成新随机序列，循环模式下每轮顺序不同
  - 跨轮边界避免上一轮末尾成为新一轮首位（堵掉"刚听过又来"的体验缺陷）
  - 关闭 shuffle 时立即恢复顺序，不打断当前播放

### 修复

- **修复 shuffle 状态泄漏**：`state.playlist.shuffle` 从前的全局态被 video/image 的 `buildPlaylist` 偷偷消费但 UI 无开关→无法切换。现改为仅 `kind === "audio"` 时才读 shuffle，video/image 永远顺序播
- **修复翻页脱节**（标签页点"下一个"后左边列表变成音频类型）：后台 `resumeLast()` / 304 分支强制覆盖 `state.tab` 但不更新视觉。现三重修复——`renderList` 自同步 tab 高亮、`resumeLast` 守卫仅首次恢复、304 分支不再覆盖 tab
- **切换标签页重置页码**：`state.listPage = 1`，避免跨类型列表长度不同导致页码残留

### 变更文件

- `web/src/modules/playlist/navigation.js`（洗牌包 + 耗尽重洗 + 状态泄漏修复）
- `web/src/modules/ui/render.js`（tab 高亮自同步 + 缩略图 retry）
- `web/src/modules/ui/bindings.js`（tab 重置页码 + shuffle toggle 定向 audio）
- `web/src/modules/player/resume.js`（resumeLast 守卫）
- `web/src/modules/actions.js`（304 分支不再覆盖 tab）
