## v1.12.0

### 修复

- **981–1024px 断点缝隙**：桌面三栏 grid 的最小内容需求为 972px + 内边距（约 1021px 视口），而移动端断点设在 980px——两者之间的窗口宽度下，右侧播放列表列被三层 `overflow:hidden` 裁剪最多 ~38px 且不可恢复。断点统一上移至 1024px（CSS 与 `mobile.js`/`play.js` 三处同步），该区间改用移动端单列布局
- **Docker 完全无法运行**：`docker compose up` 此前在构建阶段即失败（`COPY web/bun.lockb` 不存在），即便绕过也会因 `appuser` 无 `/app` 写权限在 `LoadOrInitConfig` 处 `log.Fatal` 崩溃循环；compose 的 symlink 映射还会被配置保存的 tmp+rename 语义覆盖导致数据不持久。现已端到端可用（见新功能）
- **缩略图长期陈旧**：缩略图缓存键为 `sha256(绝对路径)`（不含 mtime），媒体内容替换后服务端无限期返回旧图（7 天 max-age 仅约束客户端缓存，SWR 还会续期）。现按源文件 mtime 判定新鲜度（±2s 容差），内容变化后下次请求自动重新生成并覆盖同名文件，URL 不变无缓存抖动
- **文档与代码不符（10 处误导）**：CodeMap 热重载周期 5s→2s、`/api/progress` 参数 `mediaId`→`id`、`/api/pin` 仅 POST、媒体 ID 为 AES-GCM 加密、端点表补齐 6 个缺失端点；API_REFERENCE 补 4 个缺失端点与速率限制；TRANSCODING 探测描述改 ffprobe 优先（v1.11.0 起）；CONFIG_EXAMPLE `logLevel` 默认 `warning`、PIN 默认空；README 构建要求 Node.js→bun

### 新功能

- **桌面端播放列表列折叠/展开**：>1024px 时播放列表列可折叠（收起按钮位于面板头部，恢复入口在顶栏），播放器获得全部剩余空间（1280px 下 467→830px）；状态经 localStorage 持久化，跨断点自动恢复/清除，移动端不受影响。纯 grid 列切换，无新增面板模式
- **ffmpeg 版本日志**：启动时一次性查询 `ffmpeg -version` 并记录版本号（5s 超时），版本 <2.6 时告警——仅诊断，不拦截（所有版本敏感参数均已探测门控或低于 2014 底线）
- **对话框开合动画**：对话框/遮罩可见性由 `.dialog--open` 类驱动（opacity/visibility 过渡），此前声明的 0.3s 淡入+scale 动画被 `[hidden]{display:none}` 杀死、表现为生硬弹出；PIN 与设置对话框同步
- **内联提示替代 alert()**：设置对话框内新增内联消息（4s 自动消失，错误态 danger 色），替换添加共享失败/保存过滤成功失败/移除共享失败时的原生 alert
- **图标单一来源**：全部 inline SVG（顶栏、下拉箭头、空态、占位符等 6 处）收敛到 `icons.js` 注册表，杜绝绕过注册表的 ad-hoc SVG

### 说明

- 断点上移后，981–1024px 窗口（含 1024×768 平板横屏）使用移动布局；1025px+ 三栏
- 折叠状态键 `msp.pl.collapsed`；移动端面板切换由 mobile-nav 独立管理，互不干扰
- 缩略图 mtime 判定 ±2s 容差（粗粒度文件系统）；浏览器/SW 侧旧图最长 7 天（客户端缓存上限，非服务端）
- Docker 以 root 运行（宿主 bind mount 权限差异），`/app` 即数据卷（config/db/key/thumbs 全部持久化），首启自动播种 `/media` 共享；前端/后端构建阶段启用国内源
- 前端样式规范修正不含行为变化：对话框动画、图标注入、提示文案均为视觉层改动
