# v1.1.4 Release Notes

## 依赖安全修复

修复 GitHub Dependabot 报告的全部依赖漏洞：

| 包 | 漏洞 | 严重性 |
|---|------|--------|
| `serialize-javascript` | RCE via RegExp.flags | High |
| `serialize-javascript` | CPU 耗尽 DoS | Moderate |
| `fast-uri` | 路径遍历 / 主机混淆 | High |
| `@babel/plugin-transform-modules-systemjs` | 任意代码执行 | High |

修复方式：升级 `vite` 8.0.10 → 8.0.11、`vite-plugin-pwa` 1.2.0 → 1.3.0、`workbox-window` 7.4.0 → 7.4.1，并通过 pnpm override 强制 `serialize-javascript >= 7.0.5`。
