# 家庭/个人场景评审（main 分支）

## 总分

**8.6 / 10**

## 评审范围

- 分支：`main`
- 场景：家庭、个人使用
- 依据：项目文档、关键实现、测试与静态检查结果

## 主要加分项

1. 单文件部署与低门槛上手
- 提供单可执行文件启动方式，家庭用户部署成本低。

2. 播放策略贴合家庭 LAN 场景
- 采用“直连优先 + 必要时转码 + 失败回退”策略，兼顾兼容性与资源占用。

3. 基础稳定性较好
- 本地检查通过：`go test ./...`、`go vet ./...`。

4. 具备基本安全能力
- 支持 IP 白/黑名单与 PIN 会话认证，满足家庭内网的基本访问控制需求。

## 扣分项

1. 默认 PIN 为弱口令
- 默认值 `0000`，若用户不主动修改，存在明显安全隐患。

2. 默认安全引导仍有优化空间
- 默认 PIN 为 `0000`，即使有校验规则，仍依赖用户首次配置时主动修改。

3. 公网适用性有限
- 当前设计明确偏向家庭局域网，不建议直接公网暴露，通用部署场景受限。

## 结论

对于“家庭/个人局域网媒体服务”目标，本项目在易用性、实际播放体验和稳定性方面表现优秀；若进一步强化默认安全策略并统一文档与实现细节，评分可继续提升。
