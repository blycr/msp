基于 `docs/SECURITY_AUDIT.md` 的 19 项发现，按 4 个批次全部修复完毕，已提交到 git（commit `0dc95e2`）。

### 批次 1：P0 Critical — 速率限制 + 默认 PIN

| 修复项 | 文件 | 说明 |
|--------|------|------|
| PIN 暴力破解防护 | `internal/handler/auth.go` | 5 次错误后锁定 15 分钟，per-IP 内存计数器 |

| 全局限流器 | `internal/handler/middleware.go` | Token-bucket 算法，per-IP，Local 豁免 |

### 批次 2：P1 High — 文件流安全 + 刷新冷却 + CSP + LAN 过滤

| 修复项 | 文件 | 说明 |
|--------|------|------|
| TOCTOU 竞态修复 | `internal/handler/stream.go` | Open 后二次验证 `EvalSymlinks` + `IsAllowedFile` |
| Inline XSS 防护 | `internal/handler/stream.go` | 非媒体文件强制 `Content-Disposition: attachment` |
| Refresh DoS 冷却 | `internal/handler/media.go` | 全局 30 秒冷却 |
| CSP 头 | `internal/handler/middleware.go` | `default-src 'self'` 等 |
| LAN 过滤收紧 | `internal/handler/config.go` | LAN 时过滤 `shares.path`、`port`、`logLevel` |

### 批次 3：P2 Medium — 时序安全 + 日志注入 + 超时 + HSTS + CF IP

| 修复项 | 文件 | 说明 |
|--------|------|------|
| PIN 时序侧信道修复 | `internal/handler/auth.go` | `crypto/subtle.ConstantTimeCompare` |
| 客户端日志注入防护 | `internal/handler/progress.go` | level 白名单 + msg 截断/过滤 |
| WriteTimeout | `cmd/msp/main.go` | `WriteTimeout: 60s` |
| HSTS 头 | `internal/handler/middleware.go` | HTTPS 请求时添加 |
