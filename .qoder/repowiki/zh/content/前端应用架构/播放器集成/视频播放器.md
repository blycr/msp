## 架构总览
播放器采用“前端Plyr + 服务端转码”的混合架构。前端负责UI与交互，服务端在必要时通过FFmpeg进行转码，以兼容浏览器无法直接播放的容器或编码。

```mermaid
sequenceDiagram
participant UI as "界面"
participant Player as "player.js"
participant Plyr as "Plyr实例"
participant Media as "HTML5媒体元素"
participant Server as "服务端转码"
UI->>Player : 选择媒体并触发播放
Player->>Media : 绑定事件/设置控件
Player->>Plyr : 初始化Plyr实例(控件/全屏/存储)
Plyr->>Media : 播放/暂停/音量/速度/字幕
Media-->>Player : 解码错误/源错误
Player->>Player : 智能判断(接近尾段/源错误)
alt 需要转码
Player->>Server : 请求带偏移的转码流
Server-->>Player : 返回MP4/AAC转码流
Player->>Plyr : 切换新源并恢复播放
else 直接播放
Player->>Media : 加载原生URL
end
Player->>UI : 显示字幕/音轨/歌词
```

### 智能错误拦截与自动转码回退
- 解码错误判定：当处于播放且满足“接近片尾/剩余时间极短/流式无时长但已播放过”条件时，抑制错误并视为正常结束，避免卡死与错误提示。
- 源错误重试：对“源不可用”错误进行一次性URL刷新重试，缓解范围请求问题。
- 自动转码回退：若配置允许且当前非转码流，则切换到带偏移的转码流；若再次失败则展示可见错误提示。
- 心跳监控：若播放中超过阈值无进度推进，强制结束，防止播放器假死。

```mermaid
flowchart TD
Start(["开始"]) --> CheckErr["捕获媒体错误"]
CheckErr --> IsNearEnd{"接近片尾/流式无时长?"}
IsNearEnd --> |是| TreatAsEnd["视为结束并跳过"]
IsNearEnd --> |否| IsSrcErr{"源错误(code=4)?"}
IsSrcErr --> |是| RetryOnce["URL刷新重试一次"]
IsSrcErr --> |否| AllowTranscode{"允许转码?"}
RetryOnce --> End
TreatAsEnd --> End
AllowTranscode --> |否| ShowError["显示错误"]
AllowTranscode --> |是| SwitchToTranscode["切换到转码流(带偏移)"]
SwitchToTranscode --> End
ShowError --> End
End(["结束"])
```

## 故障排查指南
- 播放失败但提示“转码已禁用/失败”：检查服务端转码开关与FFmpeg可用性；确认客户端配置允许转码。
- 字幕/音轨不显示：确认媒体内封轨道存在；检查字幕功能开关；查看浏览器对特定容器的支持情况。
- 移动端无法全屏：确认iOS全屏回退模式开启；检查内联播放与触摸设备识别。
- 进度不同步：确认进度上报接口可用；检查本地存储权限；验证恢复播放逻辑。
